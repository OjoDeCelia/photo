Conexión

¿Cómo obtener un token?
  1. En github.com: foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: «Only select repositories», y elige el repositorio del sitio.
  3. Permissions → Repository permissions → Contents: «Read and write».
  4. Elige una fecha de expiración, confirma y copia el token (solo se muestra una vez).

El token es como una contraseña: no lo compartas. Marca «Recordar» solo en un dispositivo personal.

Colecciones y proyectos

Haz clic en una colección y luego en un proyecto para editarlo. Los textos se editan haciendo clic sobre ellos. No se aplica nada hasta pulsar «Guardar».
